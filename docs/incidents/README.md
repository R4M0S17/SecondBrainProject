# Incidents & bug write-ups

Post-mortems and fix logs for specific defects (calendar, llama.cpp migration, frontend wiring).

Files are named by area and date. New incidents should use:

`AREA-short-description-YYYY-MM-DD.md`

| File | Topic |
|------|--------|
| `CALENDAR_*.md` | Calendar tool / AppleScript regressions (May 2026) |
| `CALENDAR_DAY_QUERY_FAST_PATH_UPDATE.md` | Calendar day-query fast-path fix |
| `LLAMACPP_MIGRATION.md` | Ollama → llama.cpp migration checklist |
| `LLAMACPP_FRONTEND_FIX.md` | Tray UI + engine connection fixes |

For active remediation plans see [`../plans/`](../plans/).
